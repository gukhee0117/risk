# 위험등급 원문 확인

## 2026-11-05 최종 원문 대조와 적용 상태

사용자가 제공한 금융투자협회 참고3 원문(공식 [첨부 파일](https://law.kofia.or.kr/download.do?gubun=102&seq=27613))을 추가 확보해 본문 전체와 표·수식을 대조했다. 앞의 2026-10-28 기록에서 첨부를 확보하지 못했다고 한 부분은 당시 상태를 기록한 것이며, 현재는 첨부 원문 확인을 완료했다.

- 주식: 기본 2등급, 투자주의·경고·관리 상태일 때 1등급. 현재 KIS 분류 조회에 반영했다.
- 설정 3년 이상 ETF·펀드: VaR 표. 설정 3년 미만은 투자자산/구조 기준을 사용하고, 레버리지·인버스 펀드는 1등급으로 처리한다.
- 레버리지·인버스 ETF: 한 단계 상향. 고난도 상품은 산출 등급 3~6을 2등급으로 제한한다.
- 변동성·VaR 계산은 주식에도 유지하고 등급 판정만 상품 유형별로 분리했다.

구현은 [IMPLEMENTATION.md](../IMPLEMENTATION.md), 실제 주식 가격 표본 조사는 [KIS_PRICE_VERIFICATION.md](../KIS_PRICE_VERIFICATION.md)를 따른다. 이 적용은 문서에 언급된 전체 투자상품 유형을 구현했다는 뜻은 아니며 현재 universe의 국내 주식·ETF 및 지원 대상 펀드 범위다.

확인일: 2026-10-28. 사용자가 원문을 찾아 그 기준으로 진행하도록 요청한 데 따른 검토다.
시세 수집·계산·업무 API 코드는 이번에 작성하지 않았다.

## 1. 확보한 공식 자료와 확인 범위

- [금융위원회 2023-01-25 게시자료](https://www.fsc.go.kr/po010101/79327)의 별첨 PDF를 직접 내려받아 전체 텍스트를 읽고, 7·9쪽을 이미지로 대조했다.
  - 파일: `sources/fsc-risk-guideline-2023.pdf`
  - SHA256: `44CC40F0767D1668F5757FEE2BB9C2A18F9305B223339B74009E469C1CD06A32`
  - 원문 다운로드: https://www.fsc.go.kr/comm/getFile?fileNo=10&fileTy=ATTACH&srvcId=BBSTY1&upperNo=79327
  - 게시된 제정 당시 자료이며, 말미 시행일에 빈 날짜가 남아 있다. 이 파일만으로 현재 시행 중인 모든 세부사항을 확인했다고 간주하지 않는다.
- [금융투자협회 표준투자권유준칙 historySeq=1787](https://law.kofia.or.kr/service/law/lawFullScreenContent.do?historySeq=1787&seq=149) 본문을 확인했다. 참고 3 첨부는 다운로드 시간 초과로 확보하지 못했다. 해당 개정본 첨부 전체를 검증했다는 주장은 하지 않는다.
- [우정사업본부 투자권유준칙](https://epostbank.go.kr/upload/fund_investment_recommendation.pdf)의 21쪽 표 3에도 동일한 VaR 식과 구간이 있다. 이는 우정사업본부의 채택 문서이며 협회 첨부 원문을 대신하지 않는다.

## 2. 원문으로 확인한 사항과 이번 반영

금융위원회 첨부의 Ⅲ-2-(1), 7쪽 표 3은 설정 3년 경과 공모펀드에 최근 3년 일간수익률의 2.5퍼센타일 손실률 절대값과 √250를 곱하는 방식을 제시한다. 구간 상한은 낮은 위험부터 1%·10%·20%·30%·50%이고, 50% 초과는 1등급이다. 레버리지·인버스 ETF에는 추가 등급 상향 규정도 있다.

- [결정] 원문을 따르라는 사용자 지시에 따라 프로젝트 VaR 기본식을 `|Q2.5(일간수익률)| × √250`으로 정정한다. `-Q2.5`나 `max(0, -Q2.5)`로 대체하지 않는다.
- [확인] 기존 문서의 등급 구간은 확보한 금융위원회 첨부 표와 일치한다.
- [확인] 같은 첨부의 Ⅲ-4, 9~10쪽은 주식에 원칙적 2등급 및 조건별 상향을 제시한다. 모든 주식을 펀드 VaR 표로 분류하라는 기준은 아니다.
- [확인] 따라서 기존의 77종목 공통 VaR 등급은 프로젝트 자체 위험지표다. 원문의 공식 상품분류를 전부 구현한 것으로 설명하지 않는다. 공식 상품분류 방식으로 범위를 바꾸는 것은 기존 설계 변경이므로 자동 적용하지 않는다.
- [확인] ETF에 종가를 사용하는 프로젝트 설계와 펀드 일간수익률 기준의 대응, 레버리지·인버스 포함 여부 및 추가 보정은 별도 확인이 필요하다.

## 3. 원문이 정하지 않는 세부사항

| 항목 | 확인 결과 | 진행 기준 |
| --- | --- | --- |
| 분위수 보간 | 금융위원회 첨부에는 보간 알고리즘 지정이 없다. NumPy는 여러 방법을 지원하고 기본값은 linear다. | [제안] `method="linear"`를 명시하되 법규상 필수 방식이라고 설명하지 않는다. |
| 반올림 | 검토한 첨부에 소수 자리, 반올림 방식 및 판정 순서의 명시가 없다. | [제안] 원값으로 등급 판정 후 응답만 4자리 반올림. 반올림 방식은 미확정. |
| 최소 표본 | 과거 3년 기준과 고정 관측치 수는 다른 개념이다. 검토한 기준에 750행 의무는 없다. | [확인] 거래일 커버리지·누락 허용·공통 표본 최소 개수는 데이터 확인 후 정한다. |
| API 필드 | 프로젝트의 JSON 계약은 이 가이드라인 대상이 아니다. | [확인] `grade`/`riskGrade`는 Maria와 계약 확정 필요. |
| 시간대 | API와 Maria DATETIME 변환 규칙은 이 가이드라인에서 정하지 않는다. | [제안] 실제 시각을 오프셋 포함으로 전달하고 Maria 저장 시간대를 명시. |
| 만료 | 상품등급 재산정 주기와 이 서비스의 시세 최신성·사본 만료는 다르다. | [확인] 원문의 연간 재산정 주기를 사본 TTL로 사용하지 않는다. |

기술 근거:

- [NumPy percentile](https://numpy.org/doc/stable/reference/generated/numpy.percentile.html): 분위수 방법을 선택할 수 있다. 설치된 버전은 lock 파일을 따른다.
- [pandas DataFrame.cov](https://pandas.pydata.org/docs/reference/api/pandas.DataFrame.cov.html): 기본 ddof는 1이고 결측은 종목 쌍별로 제외한다. 결측이 있을 때 공분산 행렬의 양의 준정부호가 보장되지 않는다는 주의가 있다.
- [제안] 이에 따라 패키지는 동일 거래 구간의 공통 유효 표본을 먼저 확정하고 공분산을 계산한다. 라이브러리의 최소 실행 가능 표본 수를 3년 데이터의 품질 기준으로 대신하지 않는다.

## 4. 당시 다음 작업 (2026-10-28 기준)

아래 항목은 이 문서 작성 당시의 다음 작업 기록이다. 2026-11-05 현재 상품별 등급 기준과 현재 주식 분류 연동은 구현·검증됐다. 남은 적용 과제는 운영 별도 항목을 확인한다.

1. 시세 출처의 수정주가·조회 범위·이용 조건을 확인한다.
2. 원문 준용 범위를 명시하고, 원문에 없는 최소 표본·API 계약·운영 정책은 제안/확인으로 유지한다.
3. 기능 구현 시 절대값 부호 처리와 등급 경계뿐 아니라 원문과 프로젝트 자체 규칙의 차이를 테스트 명세에 남긴다.

원문 확인은 미확정 정책을 임의 확정하거나 Maria 코드·DDL을 변경하는 승인이 아니다.
