## 최신성·만료 합의

- [결정] 신규 결과는 배치 기준 확정 시세일 T와 종목 `priceTo`가 같을 때만 갱신한다. 날짜가 최신이어도 거래가 멈춘 채 가격이 반복되는 경우는 정상 최신 시세로 보지 않는다.
- [결정] 기존 결과는 `priceTo` 이후 최대 3거래일까지 사용할 수 있게 하고, 초과하면 계산 불가로 처리한다. DB의 이전 정상 결과는 삭제하지 않는다. `asOf`나 동기화 시각을 새로 써서 오래된 가격을 최신으로 보이게 하지 않는다.
- [결정] 만료된 종목은 `GET /grades`의 유효 목록에서 제외하고, 해당 종목이 든 패키지는 변동성 계산 불가로 응답한다. 구체적 오류 응답 계약은 구현 시 함께 정리한다.
- [확인] Maria는 응답에서 빠진 종목의 기존 사본을 보존하므로, Python에서만 제외해서는 오래된 추천 후보가 남을 수 있다. Maria 담당자와 동일한 `priceTo` 만료 기준을 적용해야 한다. Maria 코드는 이번에 변경하지 않았다.

## 다음 작업

1. 확정한 기준을 향후 계산·저장·API 테스트 명세에 반영한다. 99% 경계의 올림(예상 표본 N에 대해 ceil(0.99×N)), 연속 결측 4/5거래일, 만료 경과 3/4거래일과 휴장일 제외를 검증한다. 729개·722개를 고정 상수로 사용하지 않는다.
2. 시드 수정은 사용자 요청대로 추후 진행한다. 385720·448630을 이름에 맞춰 자동 변경하지 않는다.
3. 코드·명칭 불일치와 오래된 종목을 별도 상태로 남기고, 정상 데이터와 섞어 등급을 산정하지 않는다.
4. 실제 위험 계산은 아직 구현하지 않는다. 손계산 기대값, 등급 경계, 거래정지·결측·만료·종목별 롤백·재실행·일관된 조회를 테스트할 계획이다.
